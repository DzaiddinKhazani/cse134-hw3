Experiments

A playground for newer HTML elements: template, audio, video, source, and canvas.

Template

The template element holds markup that the browser parses but never displays. JavaScript can later clone it to stamp out new content, such as project cards. The card below is inside a template, so it stays invisible on this page.

Audio

The audio element plays sound. Each source offers a different file format, and the browser picks the first one it supports.

Video

The video element works the same way, with multiple source formats and a poster image shown before playback.

Canvas

The canvas element is a blank drawing surface that JavaScript paints on. This small fish is drawn by a short script.

Your browser does not support canvas. This is a drawing of an orange fish.

Custom Elements

page-intro is a semantic, CSS-only element that wraps the heading and introduction at the top of this page and of the Projects and Articles pages.

hello-world prints a message to the browser console without changing the page. Open your developer tools console to see it.
